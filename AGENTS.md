# Route Story — инструкции для агентов

Продукт без сборки: `index.html` + `src/*.js`, экспорт MP4 прямо в браузере, без сервера. Сдача вайбатона 15–17.10.2026. Живой сайт = ветка `main` (GitHub Pages, выкладка — обычный `git push`).

Первым делом: этот файл → `docs/CODEX-PROMPT.md` (порядок работы) → `docs/NEXT-SESSION.md` (состояние и планы).

## Запуск и проверка
- Одной командой: `bash tools/check.sh` — сервер на 4180 + все тесты (маршрут, материалы, режиссёр, smoke, своё путешествие, шрифты, рельеф, тайминги, пользовательские настройки, телефон). Должно закончиться словами `ВСЁ ПРОШЛО`.
- Вручную: `python -m http.server 4180` в папке проекта.
- Путь жюри (11 чужих файлов через интерфейс до MP4, проверка ffprobe): `node tools/judge.mjs`; `URL=https://sander419.github.io/route-story-engine/` — против живого сайта; `JURY_DIR=папка` — свои файлы.
- Глазами: `node tools/story-sheet.mjs <стиль> <short|long> <v|h>` — раскадровка ролика одной картинкой (`out/story-*.jpg`); `node tools/episode-frames.mjs <тип> <стиль> <v|h>` — кадры; `node tools/ui-tabs.mjs` — экран сайта на ноутбуке и телефоне.
- Playwright берётся из `C:/Users/glina/route-story-spike` (Edge). Без него smoke и тесты не запустятся.

## Где что лежит
- `src/ui.js` — экран: шаги «Маршрут → Текст → Фото → Оформление», заметки на маршруте, карта фото с перетаскиванием, настроения и стикеры, «Что показывать в ролике», экспорт.
- `src/director.js` — режиссёр: какие кадры и сколько секунд (детерминированно, без нейросети).
- `src/episode.js` — проигрыватель серии и стили-карты (Атлас, Полночь, Журнал V3): камера, титры, переходы, флаги, стикеры.
- `src/journal.js` — стиль «Дневник» (по умолчанию). Раскладки — `LAY` в начале файла (единицы u). Рамки-коллажи — `FRAMES` (окна измерены по альфе).
- `src/terrain.js` — 3D-рельеф (AWS Terrain Tiles, WebGL); без сети/WebGL «Дневник» рисует эскиз.
- `src/scene.js` — `STYLES` (цвета, шрифты, `deco` оформления); `src/flags.js` — флаги и гербы.
- `art/` — материалы: `pack/` (103 картинки из Obsidian, `python tools/build-pack.py`), `flags/` (249 флагов + 9 гербов), `unicycle-real.webp` (реалистичный уницикл).
- Стили сейчас: «Дневник» (`journal`), «Журнал V3» (`editorial`), «Атлас» (`paper`), «Полночь» (`night`). «Спутник» и «Навигатор» убраны по слову Саши.

## Ловушки
- После правки `src/*.js` или `style.css` — поднять `?v=` у этого файла в `index.html`, иначе браузер возьмёт старый.
- В коммит добавлять файлы поимённо (`git add src/journal.js index.html`), **никогда** `git add -A` / `git add .` — в папке лежат незакоммиченные рабочие материалы (`assets/country-symbols/`, `design/*`, `tools/codex-*`, `tools/country-*`).
- `.git` ~1,6 ГБ; pre-commit не пускает файлы >10 МБ. Ролики в git не класть.
- `out/` — мусор проверок, не в git.
- Правки кода с кириллицей делать скриптом/редактором, а не `sed` — `sed` на кириллице в этой среде молча не срабатывает.
- Overpass для городов не использовать (504). Города — из слоя `place` тайлов карты.
- Не React/Remotion/MapLibre/серверный рендер: правило «без компьютера автора», без GPU 2–4 с на кадр.

## Правила контента (нарушение = потеря доверия жюри)
- Ничего не выдумывать: нет данных — нет кадра. Погода-картинка — только по коду погоды и реальным осадкам; флаг — только если страна определилась.
- Барбос — уницикл, не собака. Км героя — «по словам автора»; путь героя по постам — пунктир с пометкой «не GPS».
- Фото с лицами посторонних и афишу с реквизитами не брать. Сгенерированные карты/фото не выдавать за реальное место.

## Правила работы
