# V2 · «Дневник в пути»

Второе направление; V1 не заменено. Выраженный скевоморфизм: реальные волокна бумаги, акварельный пигмент, тканевый скотч, рваные края, белая кромка вырезанного Барбоса, тени разной высоты. Материальность меняет силуэт и композицию кадра, а не только фон.

Машинный источник: `journal-tokens-v2.json`. Макеты: `layouts/v2/`. Координаты в u = min(W,H)/1080 px; boxU = x/y/w/h. Шкалы и безопасные зоны унаследованы из V1. Стили крупнее: заголовки/цифры 136/180 u из той же шкалы. География и значения — **пример**. SVG и PNG содержат эту отметку. Нормализованные линии маршрута/высоты не являются исходными данными.

Порядок: основная страница → бумажная вклейка → акварель/графика → стикер/полароид → скотч → текст. Декор может перекрывать края внутри одного материального коллажа. Информационные группы разделены 64 u, связанные элементы 32/16 u; перечень измеряемых разрывов для каждого кадра — groupGaps.

Вращается только один объект/коллаж в кадре. Текст полароида вращается вместе со всем полароидом; его экранный bbox проверяется после трансформации. Физические края/тени могут заходить в декоративные поля, важный текст и центр — вне верхних 8%/нижних 15%. Отдельные форматы перекомпонованы; центральный квадрат сохраняет focusBox, вспомогательная периферия не обещана.

Полароид: окно 4:5 на вертикали и 1:1 на горизонтали. Временно показан утверждённый рендер Барбоса на оформленном фоне — это демонстрация слота, **не фото путешествия**. Реальный кадр пропустить при отсутствии разрешённого фото. Место/дата и следующий пункт — только из данных. Шылпык показывать только при подтверждённом визите; пороги событий не выдуманы.

Для Canvas: непрозрачная бумага под текстом; метрики hhea и числовая baseline в токенах. Геометрия слоёв дана в blocks, текст в texts, вращение в rotation. Цифры Geologica с tnum/lnum, единицы меньше и через 32 u. Информационные поля bind — контракт для будущего адаптера, не проверенные имена полей движка. Материальные SVG-фильтры желательно запечь в raster-слои до покадрового экспорта, а текст оставить Canvas-текстом; производительность фильтров в движке не проверена.

Финал осознанно темнее остальных: светлый бумажный талон на зелёной странице. Это тональная инверсия, фиксируемая в exceptions, а не случайная смена темы. Первый вариант можно выбрать для более спокойного повествования, второй — для ощутимого предметного дневника.
