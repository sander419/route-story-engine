## Дизайн-правила (обязательны во всех задачах)
Источник — раздел волта `Атлас/Заметки/Дизайн/`. Начни с `Дизайн — инструкция для агентов.md`, машинные значения — `tokens/design-rules.yaml` (не придумывай свои), перед сдачей прогони `Чеклист — отступы и баланс.md` (разделы A–D) и `Протокол разбора — диагностика макета и кадра.md`. Для кадра читай `Композиция кадра`, `Баланс в кадре`, `Тональная структура кадра`, для текста — `Типографика — шкала, мера и ритм` и `Типографика глубже`.
Ключевое для наших кадров (база холста 1080 px по короткой стороне, дальше «ед.»):
- **Отступы** — только из шкалы `4 8 12 16 24 32 48 64 96` (крупные кратны 8), вложенные `2 6 10` — только внутри компонента. Разрыв между группами ≥ 2× внутреннего. Внутренний паддинг ≤ отступа до соседей. Одинаковые элементы — одинаковый паддинг.
- **Типографика** — не больше **7 размеров** и одна шкала с одним коэффициентом (для кадра 1.333: 32 · 44 · 56 · 76 · 100 · 136 · 180). Интерлиньяж: крупные заголовки 1.0–1.1, подписи 1.25–1.45. Трекинг: крупные заголовки **−2…−3 %** (не плюс), капс-надписи **+3…+8 %**. Иерархия минимум по двум признакам (размер + вес/яркость), **не больше трёх уровней**. Цифры счётчиков — ровные (табличные/lining), единицы меньше и приглушённее.
- **Кадр** — один центр внимания (читается за 3 секунды), лид-рум перед движением и взглядом, ничего не касается краёв случайно (зазор 1–2 %), три слоя глубины или осознанно плоский кадр, главное в центральных ~70 % (кроп 9:16 ↔ 1:1), «тяжёлое снизу, светлое сверху» или осознанная инверсия. **Безопасные зоны Reels/Shorts: верхние 8 % и нижние 15 % вертикального кадра — ничего важного.**
- **Контраст** текста ≥ 4.5:1 (крупного ≥ 3:1), цвет — не единственный носитель смысла; тест прищура и чёрно-белый — обязательны. Одно осознанное отклонение от сетки на кадр — с обоснованием.
- Правки по одной, после каждой смотреть результат. Скрипт `tools/audit_design.py` из той же папки прогонять по любому CSS, который ты пишешь.

## 3. Токены и раскладка кадров «Дневника» (`design/`)
Это нужно, чтобы Claude Code писал отрисовку по готовым координатам, а не «на глаз».
- `design/journal-tokens.json` — токены **для канваса в единицах u (u = min(W,H)/1080)**: шкала отступов, шкала шрифта (≤ 7 размеров), поля кадра (9:16 и 16:9 отдельно, кратные 4), безопасные зоны, трекинг, интерлиньяж, минимальные размеры стикеров (≥ 180 u, внутреннее поле 32 u), толщины линий. Значения берёшь из `design-rules.yaml`, отклонения — с пометкой и причиной.
- `design/journal-layouts.md` + `design/layouts/*.svg|png` — **проволочные макеты** (с реальными ассетами из задач 1, 4, 5) для шести кадров на 9:16 **и** 16:9: заставка/обложка, дорога (карта + счётчик), фото-полароид с подписью, прибытие (место + штамп/стикер), высота (профиль), финал (итог + «дальше — куда»). Для каждого: рамки блоков в u, группы и разрывы между ними (≥ 2×), где центр внимания, где лид-рум, что лежит в безопасных зонах (ничего важного), какие тексты и какой шрифт/размер/вес/трекинг. Все числа — из токенов.
- Проверка по `Чеклист — отступы и баланс` A–D: приложи в конце каждого макета список «прошло / не прошло, что исправлено». Отдельно проверь: контраст текста на бумаге и на фото (≥ 4.5:1), чтение в ч/б и в уменьшении до 25 %.
- Все надписи только из данных продукта (названия мест, км, дата, часы, погода, имя героя); примеры текста помечай «пример», не выдумывай факты.
