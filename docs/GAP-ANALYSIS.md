## Расхождения со стеком брифа — и решение

| Бриф | Решение | Почему |
|---|---|---|
| Remotion + серверный/локальный рендер MP4 | **Не переходим.** Остаётся свой рендер в браузере | Бриф сам говорит «если существует и работает — не ломай». Браузерный экспорт уже даёт настоящий MP4 с живого сайта; серверный рендер требует сервера, которого у продукта нет, и нарушает правило вайбатона «проверка без компьютера автора». Опасение PDF о «рискованном браузерном экспорте» снято замерами: 46-секундный Full HD — 2,5 мин, файлы проверены ffprobe |
| React + TypeScript + Zod | Остаёмся на JS без сборки; типы — JSDoc, проверка входа — свой валидатор | Перевод на TS/React = переписывание работающего кода без выигрыша для демо |
| D3-geo + SVG, без живых тайлов | Векторные тайлы остаются (они и есть «постер», а не скриншот карты); **добавить офлайн-подложку** world-atlas как запасную | Риск «нет сети на защите» реальный — закрываем запасной подложкой и готовым MP4 |

## Чего нет (ядро брифа) — делать

1. **Journey State с днями**: сегменты по дням, накопленный маршрут, итог, текущая позиция, чекпоинты, главы, память эпизодов.
2. **Добавление нового дня** в существующее путешествие и отчёт «что изменилось» (+км, медиа, день, итог, пересечённые вехи).
3. **Episode Director** — детерминированный: типы эпизода (new-viewer / returning-viewer / story-so-far), биты, кандидаты, eligibility отдельно от score, utility-скоринг, память последних 3–5 серий, подгонка длительности (22–26 с, жёстко 18–30), валидация, fallback, журнал решений.
4. **Shot Recipes** (≈9): DayCard, ProgressOverview, OverviewToDetail, RouteReveal, CheckpointArrival, PhotoReveal, NoteCard, DistanceCounter, DayBarcode, Pullback (+ JourneyRecap для story-so-far). Решение — отдельно от отрисовки.
5. **Проигрыватель плана**: EpisodePlan JSON → кадры на существующем холсте → тот же экспорт MP4.
6. **Hero Pullback** и **Day Barcode** — фирменные кадры.
7. **Демо-набор на 40–60 дней** + «День 47» для показа + 10 синтетических тестов режиссёра.
8. **Debug-панель**: тип эпизода, биты, кандидаты и баллы.
9. **Запасной готовый MP4** демо-сценария.

## Честность данных (из волта, не нарушать)

- Настоящего GPS героя нет. Демо-путешествие на 47 дней — **вымышленный путешественник на реальных дорогах OSM**, это подписано. Данные героя остаются в режиме «весь путь» по постам.
- Фото героя — только 9 разрешённых, без посторонних лиц. Для демо-путешествия — фото с открытой лицензией с подписью автора или фото, которые добавляет пользователь.
