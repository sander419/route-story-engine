# Шрифты проекта

Хранятся в репозитории, из сети не грузятся. Источник — Typography Collection 2026 (волт, `Атлас/Заметки/Дизайн/`), все семейства SIL OFL 1.1. Тексты лицензий — в `licenses/`. Сборка воспроизводится: `python tools/build-fonts.py "<путь к Typography Collection 2026>"` (нужны `fonttools`, `brotli`). Проверка: `node tools/fonts-test.mjs`.

| Семейство в CSS | Файл | Роль | Изменения |
|---|---|---|---|
| Yeseva One | `yeseva-one.woff2` | заголовки стиля «Атлас» | нет (файл коллекции) |
| Marck Script | `marck-script.woff2` | пометки от руки | нет (файл коллекции) |
| RS Geologica | `geologica.woff2` | основной текст, заголовки «Спутника» | подмножество, одна ось жирности 400–800 |
| RS Geologica Num | `geologica-num.woff2` | цифры данных (счётчики, часы, погода) | то же + табличные цифры по умолчанию |
| RS DINish | `dinish.woff2` | заголовки и цифры «Полночи» и «Навигатора» | подмножество, жирность 400–800, табличные цифры по умолчанию |

Почему так:
- В лицензиях Yeseva One и Marck Script указано Reserved Font Name, поэтому их содержимое не менялось. Geologica и DINish изменены, поэтому носят другое имя (`RS …`).
- Табличные цифры вшиты в сами файлы: на canvas `font-feature-settings` включить нельзя, а счётчики не должны «прыгать» по ширине.
- Стрелки «→», «≈», «−», «№» есть не во всех гарнитурах; стеки шрифтов стилей (`src/scene.js`) всегда заканчиваются RS Geologica, где они есть. Какие знаки в каком файле отсутствуют — `build-report.json`, проверяет `tools/fonts-test.mjs`.
- Подмножество: латиница, кириллица, пунктуация, стрелки, «−», «≈», «№», «°», «₽».
